# 世界196カ国 国名・首都名クイズ

世界地図上の位置と結び付けながら、196カ国の国名・首都・場所を反復できる地理学習Webアプリです。

公開URL: https://countryquiz-rho.vercel.app

## 特徴

- メルカトル図法の白地図と回答欄を連動表示
- 全地域、ヨーロッパ、アジア、アメリカ州、アフリカ、オセアニアの地域別出題
- 国名のみ、首都のみ、国名と首都の3モード
- 番号から国名・首都を入力する問題と、国名・首都から地図上の位置を選ぶ問題
- 全問、10問、20問、50問の問題数選択と再現可能なランダム出題
- 出題範囲を自動表示し、世界全体へ戻せる最大30倍ズーム
- 入力欄にフォーカスした国を地図上で強調表示
- 地図上の番号をクリックすると、対応する回答行へスクロール
- Enter / Shift+Enterで次・前の入力欄へ連続移動
- 回答中は正解や状態を表示せず、結果画面で正解・不正解・未回答を確認
- 結果の正解・不正解・未回答フィルターと、間違えた項目・未回答だけの再挑戦
- 日本語・英語の別名、略称、表記揺れに対応
- 旧首都などの歴史的な回答を現行の正解と分離
- 国名・首都・地図位置を独立して記録する苦手リストと項目別復習
- 学習結果に応じて最大10問を提示する「今日の復習」
- 前回の回答途中・結果を自動遷移せず明示的に再開
- 結果共有URL、OG/Twitter画像、X投稿リンク
- PC、モバイル、キーボード操作に対応

## 制作背景

世界地図と国名・首都を対応付けて覚えるには、一覧から答えるだけでなく、地理的位置を見ながら思い出して入力する学習が有効だと考えました。

そこで「白地図上の位置 ↔ 番号 ↔ 回答欄 ↔ 採点 ↔ 苦手復習」を一つの流れにまとめています。

## UI上の工夫

- 地図を固定し、回答欄だけをスクロール
- 回答欄にフォーカスすると、対応する国の形状と番号を強調
- 地図の番号を選択すると、対応する回答行を表示。矢印キーでも近い番号へ移動
- ヨーロッパやアフリカなど、国が密集した地域のための段階式ズーム
- 地域別・ランダム出題では出題範囲へ地図を自動調整
- 回答中は正解・不正解・正解答を表示せず、結果画面にまとめて表示
- 未回答と不正解を別の状態として採点
- Tabキーでモード、地図操作、番号、入力欄を移動可能

## 学習機能

苦手リストでは、国名・首都・地図上の位置を別々の項目として管理します。例えば首都だけを間違えた場合、国名を正解しても首都の苦手状態は残ります。未回答は苦手回数に加算せず、明示的に回答して不正解だった項目だけを記録します。

「今日の復習」は、正解が続くほど次回までの間隔を延ばす端末内の学習履歴と苦手リストから、復習時期に来た項目を最大10問選びます。回答や履歴はサーバーへ送信せず、ブラウザ内に保存します。

旧首都など、現在は正答として扱わない歴史的な回答は、現行の正解とは別に保持し、結果画面で補足を表示します。

## 196カ国の定義

国データは `world-countries` を基礎に生成しています。現在の生成ルールは次のとおりです。

- `world-countries` の独立国を基礎にする
- 北朝鮮（PRK）を除外する
- Cook Islands、Niue、Kosovoを追加する
- 国名、首都、ISOコード、地図キー、座標、地域、回答候補を検証し、196件でなければ生成を失敗させる

このルールは、このアプリで扱う196件の定義です。国数は資料や制度によって対象が異なるため、別の国数定義と混同しないようにしています。

## データ

- 国の基礎データ: `world-countries`
- 地図形状: Natural Earth由来の `world-atlas`
- 首都の日本語表記: [しけん.net 世界の首都ランキング](https://www.siken.net/w_ranking?stat=capital)
- 地図投影: `d3-geo` のMercator投影

首都データの取得やHTML構造が変わった場合は、件数・国名・首都・座標・重複を検証し、問題があればデータ生成を中止します。

## 技術的な工夫

- d3-geoによるMercator投影と緯度経度からのmarker配置
- aliasの正規化による日本語・英語の表記揺れ判定
- 現行のaccepted aliasとhistorical answerの分離
- LocalStorageのバージョン移行を含む苦手リスト保存
- 国名・首都・位置を独立して扱う復習間隔と対象項目マスク
- 問題コードとseedを保存した再現可能なランダム出題
- 従来URLを維持した地域・出題方向別ルーティング
- dynamic metadata、OG/Twitter画像、static params、sitemap、robots、manifest
- 判定・データ検証・苦手リスト処理の純粋関数テスト
